# Поля case.json

| Поле | Что писать |
|---|---|
| `id` | Имя папки. |
| `title_ru`, `title_en` | Заголовок-вопрос. Английский — для англоязычных субтитров. |
| `hook_ru` | Одна фраза-крючок. |
| `status` | `solved` — решено, `partial` — частично, `open` — не решено. |
| `date` | День, когда решение заработало. |
| `sessions` | Ветки, которые работали над задачей: название и `local_…`. |
| `commits` | Короткие хеши коммитов с решением (SF3D или игры, у игровых добавьте `game:` спереди). |
| `tags` | 2–5 слов для поиска: `hunyuan`, `bake`, `armour`, `ui`, `godot`… |
| `video.potential` | 1–5: насколько это интересно зрителю. |
| `video.why_ru`, `video.wow_moment_ru` | Почему интересно и что самое зрелищное. |
| `video.length_seconds` | Сколько секунд ролика заслуживает история. |
| `video.thumbnail` | Кадр для обложки (`src/…` или `img/…`) и 2–4 слова крупным текстом. |
| `numbers[]` | Цифры «было/стало». `better`: `lower` или `higher` — что лучше. `measured_on` — на чём мерили. `run` — для времени: `first` (первый запуск, с загрузкой нейросети) или `repeat` (повторный); для остальных цифр `null`. |
| `media[]` | Каждая картинка из `img/`. `clean` — тот же кадр без пометок и крупно в `src/`. `kind`: `render`, `screenshot`, `diagram`, `chart`, `photo`, `clip`. `role`: `problem`, `cause`, `attempt`, `before`, `after`, `result`, `context`. Кадры одной пары «до/после» получают одинаковое значение `pair`. Клип из `src/*.mp4` без картинки в `img/`: `"file": null`, `"clean": "src/….mp4"`, `"kind": "clip"`. |
| `models[]` | Пути к моделям: от корня проекта (`work/…`) или с `D:\`, для игры — `game:` и путь от корня игры. `role`: `before`, `after`, `attempt`, `reference`. `height_m` — рост в метрах. `front_yaw_deg` — поворот вокруг вертикали, при котором модель смотрит в камеру (0, если уже смотрит). `quirks_ru` — подвохи файла: «нет нормалей», «узел коллизии `*-colonly`», «ось Z вверх»; пустая строка, если их нет. |
| `beats[]` | Сцены ролика по порядку: сколько секунд, что сказать (`say_ru`: как читать вслух, имена по-русски, числа словами), что написать на экране (`sub_ru`: цифры, латиница, коротко), что показать (`show`): файлы из `img/` или `src/`, `model:<role>` — облёт модели, `diagram:<что на схеме>` — схему нарисуют для видео, `app:<путь по меню>` — запись экрана приложения. Голос читает около 14,4 знака в секунду: `seconds` ≈ длина `say_ru` / 14. |
| `reproduce_in_app` | Шаги по меню приложения, чтобы записать экран. |
| `regenerate` | Команды, которыми сделаны картинки, если они сделаны скриптом. |
