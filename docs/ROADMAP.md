## Где мы сейчас (кратко)

- Персонаж: SF3D/Hunyuan → риг по точкам (`landmarks`), 12 процедурных клипов, Mixamo FBX, детали лица, липсинк,
  исправление весов; один «Текущий персонаж» на все вкладки.
- Экипировка: подгонка готовых вещей («Броня», `landmark_editor.html`), процедурная броня и одежда
  (`armour_gen_editor.html` → `blender_armour_gen.py`), шлемы/налокотники/обувь генераторами, примерочная в Godot
  (`landmarks.wardrobe`, `godot/sf3d_wardrobe.gd`, `godot/sf3d_equip.gd`), маска тела под вещью (`body_mask.py`).
- Кисть в процедурном редакторе: щипок (тянуть / рисовать: поднять, вдавить, сгладить; формы кисти; линза сквозь
  кожу), роспись (краска, позолота, серебро, ржавчина, копоть, кровь; кисть / деталь / все такие / ластик), рисунки
  (`tool/decals`, `export/decals`), повреждения (когти, царапина, дырка). Ctrl+Z / Ctrl+Shift+Z.

## Как работать (договорённости)

- Коммит — только когда попросят; отправка на GitHub — только по явной просьбе. Коммит через Windows git:
  `cmd.exe /c "cd /d D:\My projects\SF3D && git ..."`, сообщение из файла, в конце строка `Co-Authored-By`.
- Свои файлы коммитить отдельно: в рабочей копии бывают чужие правки из других сессий.
- Приложение пользователя на 7861 не трогать. Проверки: второй экземпляр на 7871 (`D:\conda\tmp\app7861.bat`),
  процедурный редактор — тестовый сервер 7898 (`D:\conda\tmp\ag_server.bat`, копия персонажа `work/wear_proc`),
  «Броня» — 7899 (`D:\conda\tmp\armour_server.bat`). Тесты puppeteer — `work/wear_test/ui/*.mjs`.

- Godot-кадры: `D:\conda\tmp\set_shots.bat`, крупно — `gshot2.bat` / `gshot3.bat` (параметры `--pitch`, `--rise`).
- Тексты интерфейса — ключи в `tool/lang/ru.json` и `en.json`; README обновлять в обоих (`README.md`, `README.ru.md`).

### 2. Проверка брони в анимациях (QA) — [x] основа готова (2026-10-29)

- [x] `tool/blender_wear_qa.py`: вещь на анимированном персонаже примерочной (`LM._animated_model`), каждый 3-й кадр

      Пороги: кожа > 2% или дыры > 5% — предупреждение с подсказкой. ~15 с на 8 клипов.
- [ ] Картинки худших кадров; отметки по краям вещи (кожа за кромкой) отделить от настоящего «прокола» посередине.

  нормаль ладони); для каждого сустава — поворот плоскости (`S.twist`) и угол (`S.fist`). Большой палец ложится на средние
  фаланги указательного и среднего, на их внешнюю сторону (поворот основания поперёк ладони + сгиб двух суставов, перебор;
  предел основания −60…90°, за отрицательным пределом плоскость разворачивается). Перед этим костяшки среднего и
  безымянного ставятся на прямую между указательным и мизинцем (правка разметки — после неё пересобрать риг).
